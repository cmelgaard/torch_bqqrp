# torch_bqrrp

**GPU/CPU PyTorch bindings for the RandLAPACK BQRRP algorithm**, plus the **LISAO optimizer** (a momentum optimizer regularized by randomized QR/Pivoted QR).

This repository provides:

- A **C++/CUDA PyTorch extension** that exposes the following RandLAPACK routines:  
  - `BQRRP` (CPU)  
  - `BQRRP_GPU` (NVIDIA CUDA only)
- A Python API (`torch_bqrrp.bqrrp`) that calls the extension
- The **LISAO** optimizer (`lisao.py`) using BQRRP
- Example scripts:
  - Simple randomized QR demo (`bqrrp_demo.py`)
  - CIFAR-10 training using LISAO (`airbench94_lisao.py`)
- A fully self-contained dependency system:
  - All libraries (Random123, BLAS++, LAPACK++, RandBLAS, RandLAPACK)  
    are downloaded, built, and installed into `deps/` by `install.sh`

This repo is designed for **research**, **experimentation**, and **development**, not PyPI distribution.

---

# Features

### ✅ Fully self-contained build system
No global installs, no system contamination. All C++ libraries live under:

```
deps/src/       # cloned sources
deps/install/   # compiled headers and libraries
```

### ✅ CUDA acceleration
If CUDA is enabled and available, the binding exposes `BQRRP_GPU` for large matrix randomized factorization.

### ✅ PyTorch-ready
`torch_bqrrp.bqrrp()` accepts CPU or CUDA tensors and dispatches to the correct backend.

### ✅ LISAO Optimizer
Momentum optimizer regularized using BQRRP instead of standard AdamW or SGD-style updates.

### ✅ Clean developer workflow
With both:

- `install.sh`  
- `Makefile`  

you can build, clean, and test with simple commands.

## Quick Start (CUDA required by default)

From repo root:

```bash
chmod +x install.sh
./install.sh
```

This:

- Installs system packages  
- Clones/builds all dependencies into `deps/`  
- Builds the PyTorch extension  
- Runs the BQRRP demo  

To explicitly force CPU-only mode:

```bash
USE_CUDA=0 ./install.sh
```

# Python Usage

## 1. Low-level BQRRP API

```python
import torch
from torch_bqrrp import bqrrp

m, n = 5000, 2800
block_size = 900
d = block_size

A = torch.randn(m, n, device="cuda", dtype=torch.float64)

A_factored, tau, J = bqrrp(A, block_size=block_size, d=d)
```

This calls either:

- `BQRRP` on CPU  
- `BQRRP_GPU` on NVIDIA GPUs  

depending on the input tensor device and install mode.

---

## 2. LISAO Optimizer

```python
from lisao import SingleDeviceLisao

model = ...
params = [p for p in model.parameters() if p.requires_grad]

opt = SingleDeviceLisao(
    params,
    lr=0.02,
    momentum=0.9,
    weight_decay=0.001,
)

for x, y in dataloader:
    opt.zero_grad(set_to_none=True)
    loss = model(x).loss(y)
    loss.backward()
    opt.step()
```

# GPU Support

**Important:** RandLAPACK’s BQRRP GPU backend requires:

- NVIDIA GPU  
- CUDA toolkit  
- cuBLAS / cuSOLVER  

Apple MPS, ROCm, and other GPUs are not supported for BQRRP_GPU.

The CPU implementation works everywhere.

# Troubleshooting

If installation fails, common fixes include:

- Ensuring CUDA is installed and `nvcc` is on your path
- Reinstalling with:

  ```bash
  rm -rf deps
  ./install.sh
  ```

- Exporting library paths:

  ```bash
  export LD_LIBRARY_PATH=$PWD/deps/install/lib:$LD_LIBRARY_PATH
  ```

For more troubleshooting, see `INSTALL.md`.
